=== AlcorCut Pro Website ===
Requires Plugins: elementor
Requires at least: 6.0
Requires PHP: 7.4
License: GPL-2.0-or-later

The AlcorCut Pro website for Elementor: a showcase home page plus full feature lists for Capture,
the Photo editor and the Video editor.

== Install ==
1. Install and activate the free Elementor plugin.
2. Plugins → Add New → Upload Plugin → alcorcut-site.zip → Install → Activate.
3. Four pages are created and the home page becomes the site's front page (only if the site was
   still showing the latest posts there). See Settings → AlcorCut Pro website.

== Editing ==
* Open a page with "Edit with Elementor". Every section is an AlcorCut widget (left panel,
  category "AlcorCut Pro"): click it to change its texts, screenshots and links.
* Vimeo film: click the film section and paste your Vimeo link.
* Social links, beta link, Google Play link, copyright name and the glowing pointer:
  Settings → AlcorCut Pro website.
* The copyright year updates by itself ([alcorcut_year] shortcode, also usable anywhere).
* The feature lists come from data/features-*.json (taken from the app's FEATURES.md).
